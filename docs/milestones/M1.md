# M1 — referencja i profilowanie

Status: **ACTIVE**, M1 pozostaje otwarty. Bramki M1.1–M1.5 są w [MILESTONES](../../MILESTONES.md). Bieżący checkpoint i rejestr eksperymentów są w [PROGRESS](../../PROGRESS.md); ten plik zapisze krótkie dowody zamknięcia M1 po ich uzyskaniu.

Historyczna referencja anteny i porównanie pól z wycofanym storage dyskowym pozostają odrzucone jako warianty robocze. Po usunięciu disk basis ukończono też nowy resident-only run pełnej anteny FP64: jeden punkt 3,50 GHz/P2, complete=true, exit 0, 151 iteracji. Potwierdza wykonanie tego przypadku w RAM/VRAM, ale nie kwalifikuje dokładności anteny.

Dowody cząstkowe: [raport M1](../optimization-baseline.md) oraz [fazy pamięci i run pełnej anteny](../memory-phases.md). Raw residual i niezależna kontrola stopping norm są rozdzielone; coax-tiny sprawdzono względem TEM oraz między wariantami storage, a na małym problemie zweryfikowano całe pola i detekcję kontrolowanego błędu. Nowy run pełnej anteny spełnił niezależny stopping check, lecz jego raw relative residual wyniósł około 0,1253; bez porównania pełnych pól z niezależną, jakościowo zakwalifikowaną referencją jakość rozwiązania pozostaje otwarta. Nie promujemy mixed precision.

Dalszy dowód: oba porty małego coaxa przeszły analityczny E/B i całe L2 (kwadratury 4/6); tiny smoke trwał około 11–14 s, a wariant z L2 około 18 s. Zachowano FAIL 20 mm po 180 s. Wymagane bramki niezależnej jakości rozwiązania pełnej anteny pozostają otwarte.

Historyczne runy pełnej anteny z FP64/FP32 disk basis są oznaczone **REJECT** z powodu wymogu wyłącznie RAM/VRAM. Zachowany FP64-disk reference i zakończony FP32-disk field comparison nie są dopuszczalnym baseline ani promowanym wynikiem. Wcześniejszy resident FP32 run został przerwany przez RAM guard; nie ma pełnego S ani porównania pól. Nowy resident FP64 run ma zapisane S i snapshoty E/B, ale nie ma niezależnej referencji pól spełniającej bramkę jakości. Nie oznacza to ukończenia M1 ani całej kampanii. Szczegóły: [fazy pamięci](../memory-phases.md), PROGRESS i raport; starych poleceń disk basis nie odtwarzać.
