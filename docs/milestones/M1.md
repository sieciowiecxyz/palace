# M1 — referencja i profilowanie

Status: **ACTIVE**, M1 pozostaje otwarty. Bramki M1.1–M1.5 są w [MILESTONES](../../MILESTONES.md). Bieżący checkpoint i rejestr eksperymentów są w [PROGRESS](../../PROGRESS.md); ten plik zapisze krótkie dowody zamknięcia M1 po ich uzyskaniu.

Historyczne referencje z disk basis pozostają odrzucone. Po ich usunięciu ukończono resident-only FP64 run pełnej anteny dla 3,50 GHz/P2 (EXP12): complete=true, exit 0, 151 iteracji. To potwierdza wykonanie jednego punktu w RAM/VRAM, nie jakość rozwiązania. Późniejsze próby korekty EXP13/14 zakończyły się limitem 1800 s bez kompletnego solve; nie mają zakwalifikowanych S ani pól. Szczegóły i ograniczenia logowania: [korekta referencji](../reference-correction.md).

Dowody cząstkowe: [raport M1](../optimization-baseline.md), [fazy pamięci](../memory-phases.md) i [korekta referencji](../reference-correction.md). Raw residual i niezależna kontrola stopping norm są rozdzielone; coax-tiny sprawdzono względem TEM i całych pól. Referencyjny pełny run EXP12 spełnił niezależny stopping check, lecz raw relative residual wyniósł około 0,1253. EXP13/14 nie dostarczyły kompletnego rozwiązania ani kontroli pól. Bez niezależnej, jakościowo zakwalifikowanej referencji jakość pełnej anteny pozostaje otwarta. Nie promujemy mixed precision.

Dalszy dowód: oba porty małego coaxa przeszły analityczny E/B i całe L2 (kwadratury 4/6); tiny smoke trwał około 11–14 s, a wariant z L2 około 18 s. Zachowano FAIL 20 mm po 180 s. Wymagane bramki niezależnej jakości rozwiązania pełnej anteny pozostają otwarte.

Historyczne runy pełnej anteny z FP64/FP32 disk basis są oznaczone **REJECT** z powodu wymogu wyłącznie RAM/VRAM. Zachowany FP64-disk reference i FP32-disk field comparison nie są dopuszczalnym baseline. Wcześniejszy resident FP32 run został przerwany przez RAM guard. Resident FP64 EXP12 ma zapisane S i snapshoty E/B, lecz jego raw residual i brak niezależnej referencji nie spełniają bramki jakości. Korekty EXP13/14 zakończyły się timeoutem; pusty `field-comparison.json` oznacza brak pomiaru błędu pól, nie błąd większy niż 1%. Nie oznacza to ukończenia M1 ani całej kampanii. Nie odtwarzać poleceń disk basis.
